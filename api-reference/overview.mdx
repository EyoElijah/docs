The Demat Escrow API is a RESTful, JSON API. Use your merchant secret key (`sk_test_...` or `sk_live_...`) to create customers, hold funds in escrow, manage wallets, run checkout, and send payouts.

The host and key must match. Mismatches return **403**.

## Authentication

Send your secret key on every request:

```http
Authorization: Bearer sk_test_your_secret_key
Content-Type: application/json
```

Publishable keys (`pk_`) are for client-side checkout only and cannot call secret endpoints.

## Money

Amounts are integers in minor units (kobo for NGN). Send `10000` for ₦100.00.

## Idempotency

Money-moving `POST` routes require an `Idempotency-Key` header. Reuse the same key to safely retry after timeouts.
